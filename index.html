The screen is where the machine gets understood.

I build the operator side of industrial control systems — winches, carriages, mobile hydraulics. The machine already knows what is wrong. Whether the operator knows depends entirely on how the screen says it: a crowded interface turns a five-minute fault into a stopped machine, a clear one does the opposite. That is design work, and it is not decoration.

Cable-crane winch · touch panel · in service

Winch control unit

Role Screen design and navigation

Sixteen pages behind one key in one corner, reached through icons rather than words so the panel reads the same in every language. The header never moves, so wherever the operator ends up, the machine is still saying how it is doing.

Carriage · engine and radio command

Carriage control unit

Role Screen design and page layout

A dark panel, because this one is read outdoors and at night. The radio page exists for the moment the machine stops answering: instead of an error code, it shows the command itself, and the answer is on the screen before the phone call starts.
